# AGENTS

## Project overview
A small static website for a coffee shop or coffee-themed brand. The repository contains only:
- `index.html`
- `style.css`

There is no build system, no JavaScript, and no backend code.

## What AI agents should know
- Treat this as a plain HTML/CSS site.
- Keep styles in `style.css` and markup in `index.html`.
- Preserve simple structure and responsive layout.
- No commands are required to build or run the site; preview changes in the browser.

## Key files
- `index.html` — page structure and content.
- `style.css` — site styling, typography, spacing, and responsive design.

## Helpful guidance
- Use semantic HTML elements for headings, sections, navigation, and buttons.
- Prefer CSS best practices: reusable classes, mobile-first responsive rules, and minimal overrides.
- Keep the site lightweight and accessible.

## When updating
- Verify changes by opening `index.html` in a browser.
- Avoid adding unnecessary dependencies or tools.
